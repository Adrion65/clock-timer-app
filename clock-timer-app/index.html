Clock & Timer

Open the countdown and its controls as separate windows, and place each one wherever you like. There is one shared timer, so every display and control window stays in sync.

Run of show

List your segments in order. Next loads and starts the following one. The times show when each segment would end if they run back to back. Duration can be minutes (10), mm:ss (10:30) or h:mm:ss (1:05:00).

Duration buttons

Minutes, from 1 to 999. Up to 16 buttons; they are shown in order from shortest to longest.

Remote control

While this app is open, other programs on this computer can control the timer by opening web addresses. Bitfocus Companion is the main example. No internet is needed.

Set it up in Bitfocus Companion

  1. With the Clock & Timer module: add the "Clock & Timer app" connection and keep the default address and port. Then drag buttons in from Presets.
  2. Without the module: add Companion's generic HTTP connection (search for "HTTP" when adding a connection). On a button, add a press action from it, choose GET, and paste one of the addresses below.

Commands

Set duration only works while the timer is not running. To change it on a running timer, send reset first, then set. If time travel can't be turned on (for example the end time has passed), the timer stays at normal speed and the reply says why.

Changing the address

The app listens on this computer only, on port 8787. To use another port, or to let Companion on a different computer connect, start the app from a terminal with these variables set: CLOCK_TIMER_PORT=9000 for the port, and CLOCK_TIMER_HOST=0.0.0.0 to accept connections from your network. On a Mac, for example: CLOCK_TIMER_PORT=9000 "/Applications/Clock & Timer.app/Contents/MacOS/Clock & Timer"

Allowing your network means anyone on it could control the timer, so only do that on a network you trust.

Safety

The address only answers programs, not web pages in a browser, so a website can't press your timer buttons.

Timer colors
